막대그래프 = 공급가(부가세 제외) 대비 원가(검정) · 경비(회색) · 마진(빨강) 구성. 행을 클릭하면 채널별 상세가 펼쳐집니다. 판매가 미입력 채널은 빈 칸. · 수수료: 판매자배송·로켓그로스 10.8% / 스마트스토어 4.78% / 오늘의집 20.9% · 채널별 광고비는 좌측 사이드바에서 입력.
상품 마스터 스프레드시트 CSV 연동
스프레드시트 열(1행 = 헤더, 헤더 이름으로 매칭): 상품명 / 원단 / 가공 / 포장 / 부자재 / 배송 / 풀필먼트 / 판매자배송가 / 로켓그로스가 / 스마트스토어가 / 오늘의집가.
· 원가 = 원단+가공+포장+부자재.
· 풀필먼트는 로켓그로스 전용 물류비(입고+보관+배송)로, 로켓그로스 경비 = 풀필먼트+수수료+광고로 계산됩니다. 다른 채널은 배송+수수료+광고.
· 판매하지 않는 채널은 가격을 비워두면 "판매 안 함"으로 표시됩니다.
· 구글 시트: 파일 → 공유 → 웹에 게시 → 해당 시트, 형식 CSV 선택 → 생성된 링크를 붙여넣으세요.
· 시트의 로우데이터를 수정한 뒤 이 버튼으로 다시 동기화하면 됩니다. 링크는 저장되어 다음 접속 시 자동으로 불러옵니다.
